# iSmartBonus — Hackathon Development

## Existing Product

iSmartBonus existed before the Colosseum hackathon as a working
WordPress-based loyalty platform.

The existing product includes user accounts, merchant integrations,
purchase tracking, and bonus management.

## Colosseum Development

This repository contains and documents the custom development completed
for iSmartBonus during the Colosseum hackathon.

The goal of the hackathon development is to expand the existing
iSmartBonus platform with Solana-based infrastructure and improve the
connection between real-world purchases, bonus issuance, digital asset
reserves, and withdrawals.

## Technology

- WordPress
- PHP
- JavaScript
- REST APIs
- Solana
- SPL Token
